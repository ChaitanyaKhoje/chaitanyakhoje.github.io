# Image Assets

This directory stores production images used by the blog.

## Current assets

- `hero-bg.jpg` for homepage and social presentation
- post-supporting imagery such as `andromeda-galaxy.jpg` and `ring-nebula.jpg`
- `profile.jpg` for author/profile use when needed

## Guidelines

- Prefer descriptive, lowercase, hyphenated filenames.
- Optimize images for web delivery before committing.
- Keep formats simple: `jpg`, `png`, or `svg`.
- Remove unused assets when replacing them.

Do not keep placeholder images or planning notes here unless they are actively used by the site.
