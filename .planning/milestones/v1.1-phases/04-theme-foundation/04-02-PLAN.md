<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → body class | User-controlled storage value read at page load and applied as a CSS class name |
| User click → localStorage write | Toggle button click writes a string to localStorage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | localStorage 'astro-theme' key | mitigate | Validate the value before applying: only accept 'theme-atlas' or 'theme-night' — if the stored value is neither, default to 'theme-night'. Do not use the raw localStorage value as innerHTML or setAttribute on anything other than body.classList. |
| T-04-04 | Spoofing | FOUC script timing | accept | The IIFE runs synchronously in `<head>` before body paint; no async gap. Race condition is not possible in this architecture. |
| T-04-05 | Information Disclosure | Google Fonts request | accept | Fonts are loaded from Google's CDN; IP address exposure is standard practice for Google Fonts and accepted by the project. |
| T-04-06 | Denial of Service | Font load failure | accept | `display=swap` ensures text renders in fallback fonts if Google Fonts is unavailable; no layout shift risk. |
</threat_model>
